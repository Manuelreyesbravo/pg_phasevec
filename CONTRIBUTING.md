# Contributing

Bug reports, attack cases and documentation feedback are very welcome: open an issue, or for
anything that gets around the extension's rules, follow [SECURITY.md](SECURITY.md).

A good report names the PostgreSQL and pg_phasevec versions and carries a script that shows the
problem on a throwaway cluster; `test/installcheck.sh` and the `test/*.sh` suites show the shape.

Pull requests that change the code are **not accepted for now**. The project's copyright is held
by a single author so that its licensing can stay simple; if code contributions open later, it
will be under a Contributor License Agreement (a CLA, not a DCO sign-off), announced here.
